Prediction horizon: joint 16 vs autoregressive 8×2 and 4×4

The same wall-bounce event reaching 16 frames (0.67 s) three ways, with one implicit-Δt model per horizon. MOVi-spheres, held-out scenes. ← training viewer · Δt study

1. Setup

Three implicit-Δt models were trained identically except for the prediction horizon (16, 8 or 4 future frames). Each is given the same 5 ground-truth context frames and must reach frame +16 at the native 42 ms step: the 16-frame model in one joint prediction; the 8-frame model in two autoregressive passes and the 4-frame model in four, each pass taking its own previous output as context. Every pass is generated from pure noise with the diffusion-forcing pyramid sampler (25 steps) — the same rollout protocol as the original code base. Error = mean particle distance to ground truth (real meters; box width 10 m). Windows are wall-impact events: the first predicted step contains the ball–wall contact.
